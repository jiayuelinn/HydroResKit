# Sample Data

This folder contains tiny sample files used to test the HydroResKit workflow. They are placeholders and do not represent real Yangtze River Basin results.

The FCS demo dataset will later be generated from open Earth-science datasets and released with provenance records.

Files:

- `demo_indicators.csv`: synthetic full-schema indicator table for testing scoring and diagnostics.
- `hydroatlas_export_sample.csv`: tiny synthetic HydroATLAS-style export for testing the HydroATLAS mapping script. It uses HydroATLAS-like column names but does not represent a real basin.
