# HydroResKit Example Notebooks

These notebooks are lightweight examples that mirror the command-line workflow.

| Notebook | Purpose |
|---|---|
| `01_prepare_basin_units.ipynb` | Prepare Yangtze HydroBASINS units from official local source data |
| `02_build_static_indicators.ipynb` | Build HydroBASINS/HydroATLAS-derived static indicator tables |
| `03_assess_static_resilience.ipynb` | Run the static demo, diagnostics, and figures |

The notebooks do not bundle large third-party data. They assume official source files or exported CSVs have been placed locally according to `docs/release_data_policy.md`.
