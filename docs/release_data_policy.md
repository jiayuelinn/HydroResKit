# Release Data Policy

HydroResKit separates small test files, derived workflow outputs, and large third-party source data.

## Included in the Code Release

| Item | File or location | Purpose |
|---|---|---|
| Indicator schema | `configs/indicator_schema.yml` | Defines the 20 watershed resilience indicators |
| Synthetic full-schema sample | `data_sample/demo_indicators.csv` | Tests scoring, diagnostics, weighting, and figures |
| Synthetic HydroATLAS-style sample | `data_sample/hydroatlas_export_sample.csv` | Tests HydroATLAS column mapping |
| Source manifests and mappings | `configs/*.yml` | Records source IDs, mapping rules, and source-priority choices |
| Documentation | `docs/` | Usage, theory boundary, data sources, mapping, and reproducibility notes |

## Generated Locally, Not Bundled as Raw Source Data

| Item | Current local path | Why not bundled |
|---|---|---|
| HydroBASINS raw package | `data_raw/hybas_as_lev01-12_v1c.zip` | Large third-party source file; users should download from HydroSHEDS |
| Extracted HydroBASINS shapefiles | `data_raw/hybas_as_lev06_v1c/` | Derived from third-party package |
| Prepared Yangtze boundaries | `data_work/yangtze_hydrobasins_l6.geojson` | Generated by script from official source data |
| Real static indicator tables | `data_work/*.csv` | Regenerated locally from source-specific adapters |

## Downloaded or Exported by Users

| Source | Variables used by HydroResKit | Access route |
|---|---|---|
| HydroBASINS | `HYBAS_ID`, `MAIN_BAS`, `UP_AREA`, `SUB_AREA`, topology attributes | HydroSHEDS download, then `scripts/prepare_basin_units.py` |
| HydroATLAS | precipitation seasonality, climate moisture, inundation, population, urban, cropland, slope, forest, PET/AET, lake/wetland, GDP proxies | HydroATLAS download or GEE export, then `scripts/build_hydroatlas_indicators.py` |
| ERA5-Land | precipitation and drought-related climate indicators | Copernicus CDS export, then HydroResKit climate adapters |
| MODIS MOD13Q1 | NDVI condition and recovery proxies | NASA Earthdata export, then MODIS adapter |
| JRC Global Surface Water | surface-water occurrence and recovery proxies | JRC/GEE export, then water adapter |
| WorldPop or GHSL | population and built-up exposure | Official downloads or GEE exports |
| ESA WorldCover | cropland, built-up, and green-blue class fractions | Official download or GEE export |
| VIIRS Black Marble | night-light exposure, capacity, and recovery proxies | NASA export |

## Rule for the Manuscript

The letter should describe HydroResKit as a reproducible data and computation protocol. It should not claim to redistribute a new comprehensive raw basin dataset.

## HydroATLAS Full Package Status

The HydroATLAS v1.0 Figshare API reports `BasinATLAS_Data_v10.gdb.zip` as 2,695,658,577 bytes with MD5 `69af94baee68da5a3f80f09e7b85bd04`. Current command-line download attempts from this workspace returned HTTP 504/403 before data transfer began. The repository therefore keeps a full cropping command and GEE export template, but the actual full package still needs to be obtained through a browser download, another network, or authenticated Earth Engine export.
