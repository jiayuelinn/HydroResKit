# Maintenance Plan

HydroResKit is planned to remain available and maintained for at least two years after publication of the FCS Code & Data letter.

## Availability

- Keep the public code repository available.
- Archive a stable release with a DOI before or at publication.
- Keep the documentation and source manifests available with the release.

## Maintenance Tasks

| Frequency | Task |
|---|---|
| Quarterly | Check that documented source links and example commands still work |
| Twice per year | Refresh dependency compatibility notes and environment file if needed |
| After major source changes | Update source manifests, mapping caveats, and provenance examples |
| As needed | Triage issues related to installation, data adapters, and reproducibility |

## Scope Boundary

Maintenance covers code availability, documented workflows, small test data, and source-mapping logic. It does not include hosting large third-party raw datasets that should be obtained from their official providers.
