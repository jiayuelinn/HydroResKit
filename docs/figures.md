## Main Figure Notes

- Fig. 1 follows the package-overview logic used by recent FCS Code & Data letters: a top data-harmonization/audit-preparation layer, open data inputs, core package modules, result reports with small output previews, and a bottom audit/reproducibility layer.
- Fig. 2 uses the real Yangtze HydroBASINS level-6 and HydroATLAS-derived static benchmark outputs. Panel (d) is a tornado-lollipop missing-indicator sensitivity diagnostic with mean score change, IQR, 5%-95% range, and rank-change labels. The panel-level provenance is recorded in `outputs/fig2_yangtze_static_benchmark_audit.csv`.
- Fig. 3-Fig. 9 should not be listed as independent main-text figures in a short FCS Letter. They are either folded into the Fig. 2 composite, kept as supplementary/repository examples, or retained as internal pipeline verification.

## Current Limitation

The current main benchmark is static and HydroATLAS-derived. It demonstrates HydroResKit's data flow, scoring flow, and audit flow, but should not be described as the final scientific conclusion about Yangtze River Basin resilience. Dynamic event-based hazard and recovery indicators remain future extensions unless additional audited time-series data are added.
